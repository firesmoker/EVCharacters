# Liora Vey — full character-sheet example

Level 3 High Elf Bard / Tale Weaver. Source: the live EV Database — 0.53 Designer spreadsheet, checked 2026-10-15. This is a populated character template, not an all-spells reference template.

## Choices and calculations

- Bard: Magic and Melee Expert; Performance Expert; Charm, Disguise, and Acrobatics Adept.
- Origin: Focused feat; Insight Adept. Level-1 Minor Feat: Actor (requirements met).
- High Elf: Diplomacy Expert; Survival Adept from today's Knowledge Cramming; Elemental Flare and Mage Hand; Arcane Shield, Detect Magic, and Magic Missile once each per day.
- Tale Weaver: History Expert; both Beginning Phase Reenactment abilities.
- Level-3 progression: 4 SP, 1 Instinct, 6 Bardic spells, 3 Bardic cantrips. High Elf brings the totals to 9 spells and 5 cantrips. Only Bardic tradition is trained.
- DEF 2 = base 1 + Jerkin 1. FOR 1; WILL 2; Movement 3. Jerkin grants Crushing resistance.
- Shortsword roll: 5d6 Melee + 1 Extra Die = 6d6. Elemental Flare: 5d6 Magic + 3 = 8d6.
- Bardic spells: Cure, Pacify, Restoration, Aura of Truth, Silence, Sleep. Bardic cantrips: Minor Ward, Minor Illusion, Thunder Wave.

## Explicit sample assumptions

- The live Bard progression has no HP values. This example uses the class's listed 5 HP without inventing a level-based increase.
- Level 3 is treated as a milestone; the sample XP field is 0 because no XP threshold was specified.
- Common is a campaign-language assumption, in addition to the specified Elvish.
- Lute, travel supplies, and personal possessions are illustrative inventory; their acquisition and prices have not been budgeted.
- Summon Slots is set to 0 because this build has no summoning feature or spell selected.
- War Singing and Tale Weaver wording follows the current Sheet, including its explicit Inspired damage bonus; no condition-rule reconciliation was made as part of this template task.
