# Character template writing

Use real paragraphs in free-text fields. Paragraph spacing comes from the stylesheet; do not add empty paragraphs or blank lines to create spacing or fill a section.

In action-table damage cells, omit the default “SD” prefix; show the damage type. Keep explicit fixed damage amounts, such as “1 Thunder.”

Action notes must not repeat information already shown in the action table: speed, total dice, minimum roll, damage, available damage types, range, or Double 6 effects. Do not explain weapon extra dice already included in the listed roll.

Keep notes for mechanics the table does not convey, such as failure outcomes, targeting restrictions, conditions, and explanations of abbreviated effects. For example, a Shortsword action whose table already lists its stats needs only: “On failure, deal half damage, rounded down.”
